# Storm Chasers: World Break — Official Publishing Kit

This folder contains a production-ready package to publish **Storm Chasers: World Break** on Roblox with minimal follow-up work.

## What this includes
1. **Store metadata templates** (title, description, tags, short/long pitch).
2. **Thumbnail + icon production plan** using your provided concept art.
3. **Age rating/safety checklist** and moderation-safe copy rules.
4. **Launch operations runbook** (soft launch, day-1, week-1 cadence).
5. **Creator/viral toolkit** (captions, hashtags, short-form hooks).
6. **Patch notes and changelog templates**.

## Recommended publish order
1. Fill `templates/store_listing_template.md`.
2. Produce assets per `templates/thumbnail_and_icon_spec.md`.
3. Complete `checklists/pre_publish_checklist.md`.
4. Copy rollout steps from `ops/launch_runbook.md`.
5. Publish and track KPIs in `ops/kpi_dashboard_template.md`.

## Quick note on your supplied images
Your brainstorm images are strong and visually marketable. This kit is built around converting them into Roblox-safe, high CTR final assets while avoiding moderation rejection.
