# KPI Dashboard Template

Track these daily during launch week:

| KPI | Target | Day 1 | Day 2 | Day 3 | Day 7 |
|---|---:|---:|---:|---:|---:|
| CTR (impression -> click) | >= 4.0% |  |  |  |  |
| Tutorial completion | >= 70% |  |  |  |  |
| D1 retention | >= 25% |  |  |  |  |
| Avg session length | >= 12 min |  |  |  |  |
| % players seeing rare storm | >= 30% |  |  |  |  |
| % players joining co-op event | >= 40% |  |  |  |  |
| ARPDAU | baseline |  |  |  |  |
| Purchaser satisfaction sentiment | positive |  |  |  |  |

## Funnel Watchpoints
- If CTR low: replace thumbnail text and icon contrast.
- If tutorial completion low: simplify objective copy and reduce early UI noise.
- If retention low: trigger rare event earlier and shorten downtime between moments.
