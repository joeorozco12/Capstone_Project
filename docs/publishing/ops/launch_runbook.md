# Launch Runbook — Storm Chasers: World Break

## Phase 0: Closed Validation (2–4 days)
- Invite trusted testers.
- Validate first-session funnel:
  - spawn -> first weather objective -> first co-op event -> first discovery save.
- Collect top 10 confusion points and patch immediately.

## Phase 1: Soft Launch (3–7 days)
- Limited discovery traffic.
- Target metrics:
  - D1 retention >= 25%
  - Avg session >= 12 min
  - >= 30% players witness at least one rare event
- Adjust tutorial clarity and event pacing first.

## Phase 2: Public Launch
- Publish with 3+ thumbnails and updated title lockup.
- Pin update notes emphasizing:
  - Lightning Serpent event
  - Co-op storm shelter gameplay
  - Non-pay-to-win social event tools

## Day-1 Operations
- Check error logs every 2 hours.
- Run one community in-game event window.
- Patch game-breaking issues only (avoid scope creep).

## Week-1 LiveOps Cadence
- Day 2: QoL patch (onboarding confusion fixes)
- Day 4: Event pacing/balance patch
- Day 7: New mini-event + creator callout

## Incident Response Priorities
1. Data loss/save corruption
2. Purchase processing failures
3. Join/server crash issues
4. Progression blockers
5. Cosmetic/UX bugs
