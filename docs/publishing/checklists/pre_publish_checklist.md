# Pre-Publish Checklist — Storm Chasers: World Break

## Experience Readiness
- [ ] Spawn/tutorial can be completed in under 5 minutes.
- [ ] First storm event occurs within first 10 minutes.
- [ ] Lightning Serpent encounter has at least one clear server alert.
- [ ] Shelter building is required and understandable.
- [ ] Journal/discovery progress saves and reloads correctly.

## Performance Readiness
- [ ] Stable target FPS on low-end mobile test device.
- [ ] Weather effects have LOD or quality tiers.
- [ ] No major replication spikes during global events.
- [ ] Server memory and script activity are within limits.

## Monetization Readiness
- [ ] Product prompts are optional and non-spammy.
- [ ] Purchases do not gate core progression.
- [ ] Event-trigger rewards are capped/equalized.
- [ ] Product descriptions are transparent and moderation-safe.

## Store Readiness
- [ ] Icon uploaded and visible at mobile scale.
- [ ] At least 3 thumbnails uploaded and tested.
- [ ] Short + long descriptions finalized.
- [ ] Accurate tags/keywords applied.
- [ ] Social links/community group configured.

## Safety + Compliance
- [ ] Content warning copy is age-appropriate (storms/intense effects only).
- [ ] No misleading monetization claims.
- [ ] No external link violations in description.
- [ ] Privacy-safe telemetry and chat moderation on.

## Launch Readiness
- [ ] Soft-launch target cohort identified.
- [ ] Issue triage owner assigned.
- [ ] Rollback plan documented.
- [ ] Day-1 hotfix window staffed.
