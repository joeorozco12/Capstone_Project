# Project Workflow
1. Read AGENTS.md
2. Read SPEC.md
3. Read TASKS.md
4. Execute one task at a time
5. Validate each task before moving to the next
6. Update PROCESS_LOG.md after meaningful progress or failure
7. Update LESSONS_LEARNED.md when a reusable lesson is discovered

## Execution Rules
* Do not skip file reading order
* Do not batch multiple tasks together
* Do not continue past a failed validation
* Do not change project scope without updating SPEC.md
* Do not invent missing requirements; stop and flag them

## Definition of Success
* The tool matches SPEC.md
* Every task in TASKS.md is completed and validated
* README.md explains how to run and verify the tool
* Process and lessons files are updated with useful findings
